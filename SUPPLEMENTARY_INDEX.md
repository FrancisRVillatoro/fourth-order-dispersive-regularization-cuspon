# Supplementary computational materials

The files in this repository provide the deterministic numerical support for the article. The primary submission-level numerical reproduction is `code/rerun_regularized_bvp.py`, with frozen outputs in `results/` and the corresponding validation figure in `figures/`.

`code/make_cuspon_figures.py` generates the regularized-core and projected phase-plane figures. `code/y0_shoot_revised.py` and `code/y12.py` are diagnostic universal-inner computations and are not rigorous interval certificates.
